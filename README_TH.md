# แมวตัวน้อยในวันที่ฝนพรำ — Prototype 0.1

ต้นแบบ Godot 4 สำหรับเกมเลี้ยงแมวฮีลใจบน Android

## สิ่งที่มีในต้นแบบ
- สุ่มแมวจรเริ่มต้น 3 แบบ: ลายสลิด, ขาวส้ม, ส้ม
- บุคลิกแมวส้มกวน ๆ
- เมนู ลูบหัว / เกาคาง / เกาพุง / กอด / ให้อาหาร / ทำความสะอาด / พาไปเดินเล่น
- ค่าสถานะ ความหิว / ความสุข / ความสะอาด
- เงินในเกม, Meow และเพชร (ยังเป็นตัวเลขตัวอย่าง)
- ตัวอย่างการซื้อเตียงใหม่
- ปุ่มจำลองช่วงวัยลูกแมว / แมวโต / แมวแก่
- การเปลี่ยนแปลงค่าสถานะระหว่างเล่น

## เปิดโปรเจกต์
1. ติดตั้ง Godot 4.3 หรือรุ่น 4.x ที่เข้ากันได้
2. แตกไฟล์ ZIP
3. เปิด `project.godot`
4. กด F6/F5 เพื่อรันเกม

## หมายเหตุ
นี่เป็นโครงเริ่มต้นเพื่อทดสอบระบบ ยังไม่ใช่ APK พร้อมเผยแพร่ และยังใช้ emoji/กล่องสีแทนภาพจริง
ระบบเวลาจริงและบันทึกข้ามการปิดเกมยังต้องทำเพิ่ม รวมถึงภาพฉากสีน้ำ ตัวแมวแบบ 2D และแอนิเมชัน sprite จริง
